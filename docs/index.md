# Build your first game faster with GDevelop

GDevelop is a no-code and AI-powered game engine for making games without writing code. This documentation home now gives new creators a clearer path from first launch to publishing.

[Open the documentation](gdevelop5/index.md){ .md-button .md-button--primary .full-width }

[Download or try GDevelop](https://gdevelop.io/download){ .md-button .full-width }

[Get started with GDevelop](gdevelop5/getting_started/index.md){ .md-button .full-width }

## Start with the right path

<div class="grid cards" markdown>

- **New to game making?**  
  Learn the basic concepts, then follow the getting-started guide to create a first playable scene.  
  [Basic game making concepts](gdevelop5/tutorials/basic-game-making-concepts/index.md){ .md-button }

- **Building a real project?**  
  Use the feature guides to add objects, events, behaviors, assets, menus, and exports as your game grows.  
  [Open feature guides](gdevelop5/all-features/index.md){ .md-button }

- **Ready to publish?**  
  Follow the export guides for web, desktop, mobile, and store-specific release workflows.  
  [Export your game](gdevelop5/publishing/index.md){ .md-button }

</div>

## Popular next steps

- Create a scene and add objects.
- Add events for movement, scoring, collisions, and win conditions.
- Preview often, then export when the game loop is ready.
